## 📌 Deskripsi Praktikum
Praktikum ini bertujuan untuk memahami konsep dasar bahasa pemrograman JavaScript serta penerapannya dalam memanipulasi elemen HTML menggunakan **Document Object Model (DOM)**. 

Cakupan materi meliputi:
- Penyisipan berkas JavaScript eksternal (`script.js`) ke HTML.
- Penggunaan variabel (`const`, `let`), tipe data, dan operator.
- Penerapan logika percabangan (`if-else`, `switch`) dan perulangan (`for`, `while`).
- Pembuatan dan pemanggilan fungsi (*function*).
- Manipulasi elemen HTML, pengubahan gaya CSS, serta penanganan event dan validasi form.
